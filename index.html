Weeks 1–5 OOP & Design Patterns Architecture

How this JavaScript application satisfies all requirements using clean OOP boundaries and GoF design patterns.

1. Factory Pattern

ItemFactory.createItem(type, data) encapsulates instantiation logic without client code calling new on subclasses directly.

// src/factory/ItemFactory.js switch (type.toLowerCase()) { case 'standard': return new StandardItem(id, name, ...); case 'perishable': return new PerishableItem(..., expiry); case 'fragile': return new FragileItem(..., fee); }
2. Singleton Pattern

InventoryStore.getInstance() guarantees a single, central store instance throughout the app lifecycle with array CRUD methods.

// src/store/InventoryStore.js static getInstance() { if (!InventoryStore.instance) { InventoryStore.instance = new InventoryStore(); } return InventoryStore.instance; }
3. Strategy Pattern

PricingContext swappable calculation algorithms: Regular, Bulk (10% off for 5+), and Member (15% discount).

// src/strategies/PricingStrategies.js const context = new PricingContext(); context.setStrategy(new BulkPricing()); const total = context.calculateTotal(price, qty);
